# Правила проекта PCPulse

- Работа ведётся **напрямую в ветке `main`** (без создания отдельных веток и pull request).
- Единственный источник версии приложения — `<Version>` в `src/Directory.Build.props` (формат `MAJOR.MINOR.PATCH`). При любом изменении кода приложения версия повышается минимум на patch (например, `0.1.0` → `0.1.1`).
- Версия пакета контрактов `PCPulse.Contracts` задаётся отдельно в `src/PCPulse.Contracts/PCPulse.Contracts.csproj` (начальная — `1.0.0`). Повышается только при изменении публичного контракта `PCPulse.Contracts`: совместимые расширения меняют `MINOR`/`PATCH`, ломающие изменения меняют `MAJOR`.
- При изменении версий обновляйте `README.md`, если в нём указана текущая версия.
- При любом изменении кода проверяйте сборку (`dotnet build PCPulse.sln -c Release --warnaserror`) и прогоняйте тесты (`dotnet test PCPulse.sln -c Release`).
- Все изменения в репозитории фиксируются локальным коммитом в `main` до выполнения `git push`.
